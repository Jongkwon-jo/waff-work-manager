# 2026-04-02 작업 요약

## 개요
- 간트 뷰의 상태 공유, 다중 선택 작업, 일정/달력 UX, 업무 추가/수정 폼 연동을 중심으로 기능을 개선했다.
- 전략사업부/FA사업부 페이지 모두 동일 UX로 동작하도록 공통 컴포넌트와 페이지 연결을 함께 정리했다.

## 주요 변경

### 1) 간트 접기 상태 DB 공유
- 간트에서 프로젝트/업무 접기 상태를 Firestore 설정 문서에 저장/구독하도록 추가.
- 다른 사용자가 보더라도 동일한 접기 상태가 유지되도록 반영.
- 대상 파일:
  - `lib/firestore-service.ts`
  - `lib/firestore-service-fa.ts`
  - `app/work-management/page.tsx`
  - `app/fa-work-management/page.tsx`
  - `components/gantt-view.tsx`

### 2) 간트 일정 조작성 개선
- 1칸 업무(bar)에서 이동 hover/드래그가 잘 잡히도록 리사이즈 핸들 폭 로직 보정.
- 상세 보기 날짜 수정/간트 바 드래그 후 날짜 변경 시 공수 자동 계산(주말 제외 기준) 연동.

### 3) 업무 추가/수정 폼 개선
- 업무 추가에서 담당자 다중 선택 지원(쉼표 구분 저장).
- 시작일/종료일 변경 시 공수 자동 계산.
- 업무 수정 모달도 동일하게 담당자 다중 선택 + 날짜 변경 시 공수 자동 계산 적용.
- FA 페이지 문맥에서 업무 수정 기본 부서를 `FA`로 적용하도록 기본값 전달 구조 정리.

### 4) 프로젝트 구분 확장
- 프로젝트 구분에 `공사`, `A/S` 타입 추가.
- 추가/수정 다이얼로그 옵션 및 배지 색상 매핑 반영.

### 5) 다중 선택 일괄 작업
- 간트 업무 행 체크박스 다중 선택 추가.
- 상단 액션으로 `선택 삭제`, `선택 복사`, `선택 해제` 제공.
- 복사 기능은 선택 트리 구조를 유지해 생성되도록 구현.
- 키 중복 오류 방지를 위해 복사 저장 시 내부 `id` 필드 제거, Firestore 구독 시 문서 id 우선 처리로 보강.

### 6) 간트 헤더/버튼 레이아웃 정리
- 간트 헤더 2줄 구성 적용.
- 상단에 월 이동 + `새 프로젝트`, `숨김 프로젝트` 배치.
- 하단에 액션 버튼 배치, `전체 접기`/`상세 보기`를 우측 정렬.
- `선택 복사` 버튼 연한 그린 톤, `선택 해제` 버튼 연한 회색 톤으로 스타일 정리.

### 7) 달력 한글화 및 주말 색상
- 달력 캡션 `YYYY년 M월`로 한글 표기 통일.
- 요일/날짜 숫자에서 일요일(빨강), 토요일(파랑) 색상 적용.
- 월 선택 UI를 달력 캡션/드롭다운 기반으로 개선.

### 8) 기타 안정화
- 업무 추가 직후 임시 task id를 실제 DB id로 즉시 치환해 상세 수정 연동 안정성 개선.
- 간트 업무명 수정 진입을 단일 클릭에서 더블 클릭으로 변경.
- `Project & Task Details` 문구 제거.
